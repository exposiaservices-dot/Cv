# تصميم المحفظة

اقرأ `docs/PORTFOLIO_TEMPLATE_SPEC.md` و`docs/AI_PORTFOLIO_GUIDE.md`. اسأل عن الهدف واللغة والمحتوى والتصميم والأذونات؛ لا تختلق حقائق. ابدأ بـ`src/data/portfolio/index.ts`، ثم استخدم الأقسام الموجودة في `src/portfolio/Portfolio.tsx`. وسّع العقود والمكوّنات فقط عند الحاجة واختبرها. احتفظ بالبيانات الناقصة فارغة وميّز `blank` و`partial` و`complete`. راعِ العربية والاتجاه والتباين واللوحة وتقليل الحركة، واجعل المؤثرات الثقيلة اختيارية وكسولة. اختبر `npm run check` والمظهر والأجهزة الممكنة واذكر الحدود. لا تنشر دون موافقة وخطة استضافة خاصة. تعليمات المذكرات خاصة بالعرض الأصلي وليست شروطًا للمحفظة.

راجع `docs/PORTFOLIO_LIBRARIES.md` لإعادة استعمال المكتبات والمغلّفات المثبتة، وتحقق من شكل المدخل غير الموثوق باستخدام `src/portfolio/schema.ts` قبل عرضه.
