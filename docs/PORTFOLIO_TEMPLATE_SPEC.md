# مواصفة قالب المحفظة

## العقد والبيانات

المدخل الافتراضي `src/data/portfolio/index.ts`: `portfolio` للمحتوى و`portfolioDesign` للغة والاتجاه وترتيب الأقسام وظهورها والعناوين والألوان والعرض والخطوط. الأنواع في `src/portfolio/types.ts`. القيم الشخصية كلها فارغة افتراضيًا؛ القوائم الفارغة والمسافات البيضاء صالحة. لا توجد رسائل أو عناوين أقسام مرئية عندما لا يوجد محتوى. تُعرض البيانات نصيًا بواسطة React ولا تُحقن HTML.

`identity` اسم ودور وموقع؛ `about` نص؛ `projects` سجلات id وعنوان وملخص وتفاصيل ووسوم وروابط؛ `skills` نصوص؛ `experience` دور وجهة وفترة ووصف؛ `education` مؤهل ومؤسسة وفترة ووصف؛ `contact` روابط بعنوان ورابط. كل حقل يمكن تركه فارغًا أثناء الإعداد. الروابط المقبولة هي HTTP(S) وmailto وtel أو مسارات محلية تبدأ بـ `/` أو `./` أو `../` أو `#`؛ الروابط غير الآمنة أو ناقصة العنوان لا تُعرض. التحقق ليس فحصًا لملكية الرابط أو خصوصيته.

## سجل الأقسام

السجل الوحيد `sectionRegistry` في `src/portfolio/Portfolio.tsx` يربط المعرّفات بالمكونات، ويستدعيها حسب ترتيب `design.sections` و`visible`. غياب قسم من القائمة يخفيه. لا تكرر المعرّف لأن ذلك يكرر واجهة القسم. لإضافة نوع قسم، وسّع النوع والبيانات والتحقق والسجل والمكوّن والاختبارات والتوثيق معًا. الأقسام الحالية:

| المعرّف | المكوّن | يُعرض عند |
| --- | --- | --- |
| identity | Identity | اسم أو دور أو موقع غير فارغ |
| about | About | نص غير فارغ |
| projects | Projects / ProjectDetail | مشروع ذو نص أو وسم أو رابط صالح |
| skills | Skills | مهارة غير فارغة |
| experience | Experience | حقل خبرة غير فارغ |
| education | Education | حقل تعليم غير فارغ |
| contact | Contact | رابط بعنوان وعنوان URL صالحين |

الأقسام والمكوّنات مستقلة عن محرك الشرائح؛ الألوان محددة بمتغيرات CSS والنمط في `src/portfolio/portfolio.css`. اختر ألوانًا متباينة وتحقق منها؛ غيّر `lang` و`direction` معًا حسب اللغة. `typography` يستخدم سجل الخطوط المحلي القائم (`docs/TYPOGRAPHY.md`). دعم RTL يحافظ على اتصال العربية. لم تُفعّل رسوم أو WebGL في المحفظة الافتراضية؛ اختبر أي حركة مضافة مع تقليل الحركة ولوحة المفاتيح والأجهزة الصغيرة.

## التحقق والعزل

`src/portfolio/schema.ts` يستخدم Zod للتحقق من شكل المدخل غير الموثوق قبل تمريره إلى المكونات؛ الحقول الزائدة وأنواع القيم الخاطئة غير صالحة. `validatePortfolio` يقبل مدخلًا مجهولًا ويرجع `partial` ومسارات `schema.` عند فشل الشكل دون إعادة القيم. المخطط ومدقق Zod لا يُحمّلان في الصفحة الافتراضية؛ انظر `docs/PORTFOLIO_LIBRARIES.md`.

`src/portfolio/validate.ts`: `isPortfolioBlank` يتجاهل المسافات البيضاء ومُعرّفات المشاريع وحدها. `validatePortfolio` يعطي `blank` بلا أخطاء للفراغ المقصود؛ `partial` مع قائمة الحقول الأساسية الناقصة أو الروابط غير الصالحة؛ `complete` عند اسم ونبذة ومشروع ذي عنوان ورابط تواصل صالح وعدم وجود روابط غير صالحة. هذا تعريف جاهزية أدنى تقني وليس إثبات صحة أو إذن نشر، ولا يتطلب التعليم أو الخبرة. الحقول المتبقية اختيارية. لا يُطبّق مدقق العرض أو قواعد الرسائل الأكاديمية على المحفظة.

`?lab=portfolio` يستورد `PortfolioLab` كسولًا؛ بياناته الاصطناعية لا تُستورد في بيانات الصفحة الافتراضية. بقية المختبرات والمحرك الأصلي معزولة عن الصفحة، والمحرك يستورد كسولًا عبر `?mode=presentation`. المختبرات ليست بيانات إنتاج؛ لا تنشرها كهوية شخص.

## المسارات والنشر

Vite يستخدم `BASE_PATH` وقت البناء (بداية ونهاية `/` مثل `/portfolio/`)، والأيقونة تستعمل `%BASE_URL%`. اختبر على المسار الفعلي لمضيفك. لا يوجد نشر آلي؛ سير العمل اليدوي يتحقق من البناء فقط. لا تخلط الموقع الخاص بمستودع خاص؛ يلزم مضيف ومصادقة وقرار منفصل قبل النشر.
