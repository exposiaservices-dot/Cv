# بحث مكتبات للمواقع الشخصية

تاريخ البحث: 2026-11-03. هذا **بحث وترشيح فقط**؛ بعد البحث ثُبّتت `yet-another-react-lightbox` و`axe-core` واختُبر تكاملهما؛ بقية الترشيحات أدناه لم تُثبّت ولم تُختبر ضمن المشروع. الإصدارات وتراخيص الحزم المبيّنة لقطة من سجل npm وقد تتغير. معلومات peer dependencies توحي بتوافق أولي مع React 19، لكنها لا تغني عن تجربة التثبيت والاختبار والترخيص والتدقيق الأمني الفعلي.

## ما لدينا بالفعل

React 19 وVite 7 وTypeScript وTailwind، و`framer-motion` و`gsap` للحركة، و`lucide-react` للأيقونات، وZod للتحقق، والخطوط المحلية ومكتبات الرسوم والتأثيرات. انظر [فهرس مكتبات المحفظة](PORTFOLIO_LIBRARIES.md) و[الفهرس الكامل](PROJECT_LIBRARIES.md). لا حاجة لإضافة بدائل مكررة لهذه الوظائف لمجرد زيادة العدد.

## طريقة الاعتماد المقترحة

1. اختر ميزة محددة قبل إضافة حزمة؛ مثل اختبار الوصول أو تكبير صور مشاريع مصرح بها، وليس تثبيت القائمة كلها.
2. ثبّت إصدارًا متوافقًا، وراجع الترخيص والتبعيات و`npm audit`، وحدّث `package-lock.json` وفهرس المكتبات.
3. استخدم مكوّنًا اختياريًا كسولًا للواجهات الثقيلة؛ لا تُغيّر البيانات الافتراضية الفارغة أو أدوات العرض والمختبرات.
4. أضف اختبارات وحدات وتكامل ومراجعة RTL والتركيز والموبايل وتقليل الحركة، واذكر صراحةً ما لم تتمكن من اختباره.
